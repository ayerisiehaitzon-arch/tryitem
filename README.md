# Tryitem · 低面数、高质感的家具、摆件与灯具

12 件家具、5 组摆件（书、花瓶、琴叶榕、虎尾兰、地毯）、4 盏灯具（落地灯、台灯、吊灯、壁灯），
全部程序化生成，导出为通用的 glTF（`.glb`）。单件 **150 ~ 2,018 个三角面**，全套 LOD0 加起来约 19,000 个三角面，
但近看依然是“精模”的观感：圆润的倒角高光、柔软的坐垫、对花的木门、黄铜脚套、布纹、手工釉面、叶脉、透光的纸灯笼、
接缝里的阴影、落地的接触阴影，灯具还带着烘焙的光斑。

## 为什么面少还好看

### 1. 倒角 + 加权法线

完全锐利的直角在现实里不存在，也接不住高光，这是低模“塑料感”的主要来源。
每条看得见的棱都加一条窄倒角，并且**倒角两侧顶点的法线直接取相邻大面的法线**：

- 大面四个顶点法线完全一致，所以大面绝对平整；
- 倒角那一窄条的法线从一个面过渡到另一个面，着色上看就是一个圆角，边缘会亮起一道高光。

一个倒角盒子是 44 个三角形（直角盒 12 个），顶点数几乎不变，观感差别却很大。
下图从左到右：正常着色、去掉法线技巧后的真实面、线框。

![法线对比](docs/previews/normals.jpg)

### 2. 面只花在轮廓上

- 平整的大面永远只有 2 个三角形，细分只加在轮廓和需要形变的方向；
- 圆形部件按直径给分段：细腿 8 段、Ø800 台面 44 段（轮廓误差约 1mm），明暗靠平滑法线；
- 看不见的面直接不生成：插进桌面的腿顶、坐垫底面、层板两端、贴地的灯座底面；
  只省**完全**被挡住的面：办公椅外壳比靠垫大一圈，朝前的一面会从靠垫圆角后面露出一道边，省了它就会从缝里看穿背景，
  所以省的是靠垫背面（腰托只鼓前面，靠垫背面始终贴着外壳）；座面外壳的顶面同理保留，它只是一个四边形；
- 只倒看得见的棱：牵条只倒下沿两条，藏在桌面下和腿里的面不倒角；
- 能一次成形就不拼：办公椅的五星脚是一个星形截面挤出一次（带圆头），再加一个“脚尖下垂”的形变，
  比五根扫掠管省一半以上的面；衣柜的 D 形拉手是一条扫掠路径（立脚 + 横杆），拐角做斜接不会变细。

### 3. 软体：圆角盒 + 鼓胀形变

坐垫、靠垫、床垫、枕头都是同一个圆角盒，加一个光滑的多项式形变：顶面中央拱起、侧面微凸、
棱边不动。法线用形变的雅可比矩阵变换（而不是重新从三角形计算），
所以 136 ~ 328 个三角形的坐垫也有柔和连续的明暗。被子的“垂边”、办公椅座面前沿的“瀑布”下弯、
盾形靠背的轮廓、两侧前包和腰托也都是形变，只在需要弯的方向加节点。

### 4. 烘焙 AO（所有 LOD 共用一张图）

每件家具有第二套 UV（`TEXCOORD_1`），自动展开并装箱成一张 128² ~ 512² 的 AO 图集，
用 BVH 光线追踪烘焙（包括地面遮挡）。图块按稳定的 id 排布，LOD1、LOD2 直接复用 LOD0 的图集，
不需要额外贴图。下图左边有 AO，右边没有：坐垫与框架的接缝、扶手下方的体积感差别就在这里。

![AO 对比](docs/previews/ao.jpg)

### 5. 烘焙接触阴影贴花

每件家具自带一个 `<id>_Shadow` 节点：一个贴地四边形 + 一张很小的半透明阴影图。
场景里不用实时阴影也能“落地”，省掉一整遍阴影贴图渲染。需要实时阴影时隐藏它即可。
物体自己贴地盖住的那块地面（比如地毯底下）贴花是完全透明的：那里本来就看不见，
也避免了远看时贴花从薄薄的物体底下“透”上来。

### 6. 贴图复用

- 家具只有 6 套材质贴图（橡木、胡桃木、亚麻、圈绒、皮革、大理石），所有家具共享（摆件的图集见后文）；
- 亚麻一张贴图靠 `baseColorFactor` 染出燕麦色、米白、炭灰、灯罩色，贴图内存只占一份；
- 金属、烤漆、塑料没有可见纹理，只用参数，不占贴图；
- 法线、粗糙度图用颜色图一半的分辨率（细节主要在颜色图上）；
- 贴图全部程序生成、可无缝平铺，按真实尺寸映射（木纹沿部件长度方向）；实木桌面由宽窄不一的板条拼成。

### 7. 三级 LOD

每个 `.glb` 里有 `LOD0 / LOD1 / LOD2` 三个节点：LOD1 大约减半，LOD2 只保留外形。
预览器按“屏幕尺寸”自动切换（包围球投影半径 ≥110px 用 LOD0，≥45px 用 LOD1）。

## 家具精修：细节不靠堆面

衣柜、书桌、办公椅（连同床头柜）又精修了一轮：近看多了好几处“讲究”，面数基本没变 ——
衣柜 +4%、床头柜 +8%、办公椅 +5%，书桌多了一个抽屉 +17%。

![家具特写](docs/previews/furniture-detail.jpg)

### 8. 木纹“对花”

好的木门会把一张木皮对剖开、左右翻开贴在两扇门上，花纹沿门缝镜像对称（book-matching）。
这里一个面都不加，只动 UV：

- 部件可以指定 `uvKey`：几块板共用同一个木纹随机偏移，像从同一块料上裁下来；
- 衣柜的右门用左门的镜像变换生成，两扇门的山纹就沿门缝左右对称；
- 两个抽屉面板共用木纹，再按各自的高度平移（`uvShift`，单位米）：木纹跨过抽屉缝上下连续；
- 反过来也要留意：书桌小书架的背板从后面看，正好落在木纹对称的中线上，像一张镜像贴图，就给它换一块木纹。

### 9. 黄铜脚套

衣柜、床头柜、书桌的锥形腿最下一截换成黄铜脚套，和拉手、把手呼应。
脚套是把腿的车削轮廓在最下面切出一截、外径放大 0.8mm 换成黄铜（顶上留一道小台阶，看得出是套上去的），
贴地看不见的底面不生成，每条腿只多 8 个三角形；
LOD2 把脚套并回木材材质，不多一次 draw call。书桌小书架的左格里还多了一个信件抽屉（面板 + 黄铜小把手）。

### 10. 办公椅：盾形靠背

- 靠背轮廓是一个形变：上部两角收圆、上沿微拱，两侧前包（越往下包得越深），腰托只鼓前面；
- 外壳用同一个形变（不带腰托），比靠垫大一圈：朝前的一面从靠垫圆角后面露出一道黑边，同时封住靠垫背后，
  所以靠垫背面可以不生成；外壳没有腰托，竖向只在上部收圆处要节点；
- 座面两侧微微隆起托住大腿、中间略凹，前沿“瀑布式”下弯；
- 铝脊是扫掠时截面越往上越大的一支“桨”，扶手垫前宽后窄（线性形变，不加节点），座下多了张力旋钮（只在 LOD0）；
- 省下来的面补给了曲面：轮子、气压杆、扶手支架各减几段，靠背的节点只放在前包的抛物线、腰托和上部收圆这几处。

## 摆件：一张图集、一个材质

摆件又小又多，最怕的是“每件都带一堆贴图和材质”。这里每一类摆件只用一个材质、一次绘制，
贴图里的每个像素都知道自己画在物体的哪个位置。

![摆件特写](docs/previews/decor-detail.jpg)

### 11. 调色板图集（书）

12 本书只有 1 个材质、1 次 draw call：书脊图案、封面颜色、书页侧边都画在一张 512² 的图集里，
每本书的 UV 指向自己的格子（16 种布面配色，4 种书脊样式）。

- 烫金是真金属（金属度贴图），灯下会闪；书名是一个个宽窄不一的“字块”加词间空格，远看就是一行字；
- 书脊格子是 32×320 的细长条，竖向像素多，横线和小字才清楚；颜色图不做色度抽样（4:4:4），金线不糊；
- 几何上只有三处细节，但都是“书之所以像书”的关键：书脊是椭圆弧、封面比书页四周多出 3mm、
  书页顶面和前口内缩；立着的书底面看不见，直接不生成。

### 12. 按曲线绘制的釉面（花瓶、花盆）

器型是一条“设计曲线”（Catmull-Rom 样条 + 拐角），几何和贴图共用它：

- 几何：轮廓按剪影误差自适应取点（LOD0 1mm、LOD1 2.2mm、LOD2 6mm），圆周分段按同样的误差选，
  法线取曲线的真实法线 —— 平直处一个点都不浪费，口沿这种小圆角也不会被切成一圈圈台阶；
- 贴图：u 绕一圈、v 是弧长。生成器沿同一条曲线知道每一行像素的高度、半径、凹凸，所以
  蘸釉线和流釉、底足露胎、口沿釉薄发色、凹处积釉、拉坯旋纹都画在正确的位置；
  铁点按真实面积撒、在物理空间里画成圆，到了细颈也不会被压扁；
- 三只花瓶和两个花盆共用一张 1024² 的陶瓷图集（白釉、青釉、天目釉、石墨釉各一块），一个材质。

### 13. 几何叶片（绿植）

叶子不用透明贴图抠形，而是真实轮廓（每片 3 列 × 3 ~ 10 行）：没有 alpha 测试的锯齿、没有透明排序和过度绘制。

- 叶片沿主脉折成 V 形、沿长度下垂，叶缘的法线再往里多倾一倍折角 —— 只有 3 列点，也有微微卷起的圆润明暗；
- 琴叶榕 28 片叶按黄金角螺旋排列，下部叶大而下垂、顶部新叶小而直立；虎尾兰叶片带 V 形槽并各自扭转；
- 叶脉、树皮、盆土都在一张植物图集里；花盆用上面的陶瓷图集。

### 14. 整幅图案 + 平铺细节法线（地毯）

- 颜色是一整幅 2m × 1.4m 的手绘菱格（Beni Ourain 风格），线条有手工的抖动和偶尔的断口；
- 羊毛绒面是另一小块 0.25m 见方的可平铺法线，材质里用 `KHR_texture_transform` 重复 8 × 5.6 次 ——
  大图案和毫米级绒面同时成立，而地毯本体只有 142 个三角形；
- 流苏是贴地卡片 + alpha 裁剪，每端 4 个三角形；透明裁剪的面片不参与 AO / 阴影烘焙的遮挡，
  否则地上会压出一条黑带。

## 灯具：开灯不加一盏实时光源

灯具最容易做成“一个发白的物体”。这里每盏灯的“亮”都来自三样很便宜的东西：自发光材质、
烘焙在安装面上的光斑贴花、以及贴图里画好的透光效果。整个场景没有一盏实时光源，也不需要额外的阴影贴图。

![灯具特写](docs/previews/lighting-detail.jpg)

### 15. 烘焙光斑

每盏灯自带一个 `<id>_Glow` 节点：安装面上的一个四边形 + 一张 alpha 贴图。烘焙时把灯泡当作一个小球光源，
按 cosθ / d² 算它照在桌面、墙面或地面上的直射光：

- 不透光的部件挡出影子（台灯灯座周围那一圈暗环、壁灯灯臂在墙上的影子）；
- 半透明的灯罩按透光率打折（亚麻约 30%），发光体本身（灯泡、乳白玻璃）不挡光；
- 光源半径取发光面的大小（台灯取灯罩下口 8cm、壁灯取玻璃球 7cm），影子边缘是软的；
- 光斑只覆盖灯附近一小块、边缘淡出：台灯放在小床头柜上也不会伸出桌边。

预览器用加法混合把它叠在表面上；“灯光”开关一关，自发光归零、光斑隐藏。开灯的全部代价是 2 个三角形和一张小贴图。

### 16. 百褶灯罩

台灯灯罩是真正的折线截面：36 个褶、72 个褶面。所有折痕都指向锥顶，所以每个褶面都是平面，
上下两圈顶点就够；折痕处法线断开，灯光下一明一暗，上下边缘是锯齿。LOD2 用同一个图块退化成光滑锥面。
灯座是一条设计曲线（和花瓶同一套车削工具），牛血红釉的高光一路圆过去。

### 17. 纸灯笼：白天一张图，点亮一张图

吊灯是 Akari 式的竹骨纸灯笼，整只灯笼一张贴图，沿设计曲线来画：

- 竹骨是一条真正的螺旋线（弧长 s = s₀ + 螺距 × u），绕一圈正好接上下一圈，接缝处无缝；
- 纸片重叠的接缝、上下口包边、楮树皮纤维都按物理尺寸画；
- 颜色图是白天看到的纸，竹骨只是浅浅一道棱；另有一张自发光图是点亮后的样子：竹骨挡光成了深色螺旋线，
  纸的云状厚薄透出来，离灯泡近、正对灯泡的地方更亮。

### 18. 安装面

`floor`（落地 / 放在台面上）、`wall`（壁挂）、`ceiling`（吊装）三种。原点就在安装面上，导入引擎直接贴上去：

- 壁灯：z = 0 是墙面，灯朝 +z 伸出；吊灯：y = 0 是天花板，灯挂在 -y 一侧；
- AO 烘焙把安装面算作遮挡（壁灯底盘贴墙的一圈自然变暗），接触阴影和光斑也都画在安装面上；
- 预览器单独展示壁灯时，身后是一面和背景同色的“无缝墙”；吊灯挂在 2.45m 高处。

## 目录

```
src/

  prims/       挤出（带倒角）、圆角盒（软体）、车削、扫掠

  materials/   程序化贴图、材质库
  furniture/   每件家具一个文件（index.js 是全部清单）

  lighting/    灯具：落地灯、台灯、纸灯笼吊灯、壁灯
  export/      glTF 组装
scripts/       构建、预览服务器、截图、检查工具
viewer/        Three.js 预览器
models/        构建产物：<id>.glb + manifest.json
```

## 使用

```bash
npm install
npm run build                 # 生成全部家具到 models/（约 1 分钟，AO 用多线程烘焙）
npm run build -- sofa bed     # 只构建指定家具
npm run build -- --fast       # 低采样、低分辨率贴图，调试用
npm run serve                 # 打开 http://localhost:8080/viewer/
npm run inspect models/sofa.glb   # 查看节点、面数、材质、贴图
npm run previews              # 重新生成 README 里的预览图（需要 Playwright 的 Chromium）
node scripts/export-gltf-json.js out/   # 转成 JSON glTF（二进制内嵌），给只能托管文本的地方用
```

### 导入引擎

`.glb` 自包含（几何 + 贴图 + AO + 阴影贴花），可以直接拖进 Blender、Three.js、Babylon.js、
Godot 4，Unity 用 glTFast，Unreal 用自带的 glTF 导入。

- 节点命名：`<id>_LOD0/1/2`、`<id>_Shadow`，按引擎的 LOD 约定挂到 LOD 组上；
- AO 在材质的 `occlusionTexture` 上，使用 `TEXCOORD_1`；
- 布料、羊毛用了 `KHR_materials_sheen`，胡桃木、烤漆用了 `KHR_materials_clearcoat`，
  阴影贴花用了 `KHR_materials_unlit`，地毯的绒面法线用了 `KHR_texture_transform`；
  不支持这些扩展的引擎会退回普通 PBR，外观基本不变；
- 叶片、流苏、灯罩、纸灯笼是双面材质，流苏用 `alphaMode: MASK`；
- 灯具的 `<id>_Glow` 光斑贴花是 unlit + alpha blend，建议在引擎里改成加法混合（像预览器那样）；
  壁灯、吊灯的原点在墙面 / 天花板上（见上文“安装面”），模型的 extras 里有 `mount` 字段；
- 尺寸单位是米，Y 轴向上，家具正面朝 +Z，底面落在 y = 0。

### 新增一件家具 / 摆件

在 `src/furniture/`（或 `src/decor/`）里写一个 `build(k)`，再加进 `src/furniture/index.js`；
摆件加上 `category: 'decor'`、灯具加上 `category: 'lighting'`，预览器会分组显示；
壁挂 / 吊装的加上 `mount: 'wall'` / `'ceiling'`，灯具再给一个 `glow: { light: [灯泡位置] }` 就会烘焙光斑。
同一个函数会以 LOD0/1/2 各运行一次，用 `k.q(LOD0值, LOD1值, LOD2值)` 取不同精度的参数：

```js
import { rect } from '../core/shape.js';
import { xf } from '../core/vec.js';

export default {
  id: 'side_table', name: '边几', nameEn: 'Side Table',
  build(k) {
    const q = (...v) => k.q(...v);
    // 桌面：平面圆角 + 上沿圆边（加权法线倒角）
    k.extrude({
      name: 'top', mat: 'walnut', axis: 'y', depth: 0.022,
      shape: rect(0.5, 0.5, { r: q(0.02, 0.02, 0), segs: q(3, 2, 1) }),
      bevel: q(0.003, 0.003, 0), bsegs: 1,
      xf: xf({ pos: [0, 0.5, 0] }),
    });
    // 软垫：圆角盒 + 鼓胀，底面省略
    k.box({
      name: 'pad', mat: 'linen', size: [0.4, 0.05, 0.4], r: 0.02, segs: q(2, 1, 0),
      div: q([2, 1, 2], 1, 1), puff: q({ top: 0.01 }, null, null), omit: ['ny'],
      xf: xf({ pos: [0, 0.547, 0] }),
    });
  },
};
```

材质名见 `src/materials/library.js`。部件名（`name`）在一件家具里要唯一，AO 图集靠它在各级 LOD 之间对齐。

## 已知取舍

- 圆形部件在极近距离下能看出多边形轮廓，这是低模的正常代价；需要时把对应的 `segs` 调大；
- 每个 `.glb` 自带一份材质贴图，方便单独导入。批量用在同一个场景时，按贴图名去重
  （预览器就是这样做的）即可只占一份显存；
- 贴图是 JPEG；上线前可以再转成 KTX2 / Basis，显存还能再降到 1/4 左右；
- 接触阴影贴花是贴地的：摆件放在家具上时（书在层板上、花瓶在茶几上），贴花按摆件自己的占地收小，
  不会伸出台面；家具放在地毯上时，预览器把它的贴花抬到地毯面上（否则会被 2cm 厚的地毯挡住）；
- 流苏是 alpha 裁剪：远处 mip 会把细线平均掉，所以阈值取得偏低（0.35），远看是一条完整的流苏边；
- 光斑贴花是按“灯立在一个平面上”烘焙的：台灯放在比光斑（直径 60cm）还小的台面上时，边缘会伸出去一点；
  吊灯离桌面的高度不固定，所以不带光斑，只靠灯笼本身发光。
